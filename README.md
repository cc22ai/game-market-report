# 中国游戏市场月度 / 季度数据报告（伽马数据 CNG / CGIGC）

基于伽马数据（CNG）与中国音数协游戏工委《中国游戏产业月度 / 季度报告》口径，整理 **2024-01 至 2026-09** 的月度与季度数据，并标注主要贡献同比增长的游戏。

- 数据范围：2024-01 ~ 2026-09（33 个月度 + 11 个季度）
- 增长归因：核心引擎从 2024Q3《黑神话：悟空》→ 2025Q1《DNF：起源》+《无尽冬日》→ 2026 端游 + 双端互通（《三角洲行动》《王者荣耀》等被点名）
- 图表：内联 ECharts，**无需联网即可渲染**
- 数据性质：官方披露 / 推算 已在文中逐月标注
